## What it does

Creators sell pay-per-view tickets for virtual live events, gate the stream to paying fans and withdraw earnings to M-Pesa or a bank. Fans anywhere buy with just an email: no account, no app.

## Highlights

- Pay-per-view ticketing with hosted checkout
- Low-latency stream gated to ticket holders
- Creator wallet with M-Pesa and bank withdrawals
- Earnings analytics

## Built with

Next.js · React · Convex · Clerk · Tailwind CSS · Motion · Recharts
